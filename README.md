# ИИ-сомелье для сети супермаркетов: при каких условиях он может окупиться

Портфолио-кейс по категорийному маркетингу и продукту с ИИ: концепция и экономика
ИИ-консультанта по вину для региональной сети супермаркетов премиального сегмента,
март 2026 года. Объём категории и сверка с оценкой заказчика, эффект в выручке и
в марже с учётом охвата, порог окупаемости, правовые ограничения каналов, MVP и
гипотезы с критериями GO/PIVOT/STOP.

**Страница кейса:** [massimo-pazzi.github.io/wine-ai-case](https://massimo-pazzi.github.io/wine-ai-case/)

Заказчик не называется. Концепция и отчёт проекта не публикуются.

## Структура

```
index.html              страница кейса (собирается скриптом)
report/case.md          текст кейса
scripts/model.py        объём категории, два уровня оценки эффекта, порог окупаемости
scripts/build_page.py   сборка страницы из текста и модели
data/                   результаты расчётов в CSV
```

## Как пересчитать

```bash
python3 scripts/model.py
python3 -m venv .venv && .venv/bin/pip install -r requirements.txt
.venv/bin/python scripts/build_page.py
```
